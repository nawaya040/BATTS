The local drawing validation used R 4.5.2 with `ggplot2` 4.0.3, `patchwork` 1.3.2, `scales` 1.4.0, `mvtnorm` 1.3.3, and `pracma` 2.4.6. The 2D light run used the archived Round 1 library: `ReviewPkg` 0.0.0.9000, `densratio` 0.2.1, `mvtnorm` 1.3.6, and `ada` 2.0.5.1. The light estimator entry point requires those four packages and, for 20D, `pracma`. Full Round 2 recomputation has further dependencies described by the workflow READMEs in `code/r2/scripts/`. Package versions, compiler version, operating system, RNG kind, seed mapping, worker count, and input/output hashes for an official rerun must be written to a new run manifest. The saved results contain their original provenance files, with machine paths aliased in the release copies.

This candidate deliberately omits the Round 1 installed `r_lib/` directory because its binaries depend on the originating platform.
